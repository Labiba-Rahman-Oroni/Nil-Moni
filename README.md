# NIL MONI | নীল মণি

**Bengali traditional and modern fashion jewellery, online.**

NIL MONI is a bilingual (Bangla and English) jewellery eCommerce website for customers in Bangladesh. It is being built step by step as a real business platform.

> 🚧 **Status:** Work in progress. Product data shown in the site is sample data until real products are added.

## Tech stack

| Area | Technology |
|---|---|
| Frontend | Next.js (App Router), React, TypeScript, Tailwind CSS v4 |
| Icons | Lucide React |
| Backend (planned) | Node.js, Express.js, REST API |
| Database (planned) | MySQL with Prisma ORM |
| Images (planned) | Cloudinary |
| Payments (planned) | Cash on Delivery, bKash, Nagad, SSLCommerz |
| Deployment (planned) | Vercel |

## Getting started

You need [Node.js](https://nodejs.org/) installed.

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.
